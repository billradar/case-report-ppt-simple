# 卵巢癌 · 妇科【疑难】

## 元信息

- ID：GYN-OVCA-06
- 科室：妇科 / 肿瘤科
- 病种：卵巢上皮性癌（高级别浆液性，Ⅲ C 期）
- 类型：**疑难**（腹胀腹水易误诊为消化病，早期难发现）
- 人群：女，58 岁
- 关键教学点："沉默"肿瘤、腹胀腹水为常见表现；CA125 + 超声/CT；肿瘤细胞减灭 + 化疗
- 适用：疑难病例讨论 / 教学查房

---

## 一、入院记录

### 主诉
腹胀、食欲下降 2 个月，腹部增大 2 周。

### 现病史
2 个月来腹胀、食欲差、早饱、消瘦，曾在消化科按"消化不良/腹水"治疗无好转。2 周来腹部明显增大、气促。无异常阴道流血、无发热。既往绝经 7 年。

### 既往史 / 个人史 / 婚育史 / 家族史 / 过敏史
绝经 7 年；G2P1；无肿瘤史，无家族肿瘤史（未筛查 BRCA）；无药物过敏史。

### 体格检查
- 生命体征：T 36.6℃，P 92 次/分，R 20 次/分，BP 126/78 mmHg。
- 系统查体：腹部膨隆、移动性浊音（+）；妇科检查后穹隆可及触痛结节、附件区可及包块；无下肢水肿。

### 辅助检查
| 项目 | 结果 | 参考区间 | 时点 |
| --- | --- | --- | --- |
| CA125 | 860 U/mL ↑ | <35 | 入院 |
| 妇科超声 | 双侧附件区实性/混合性包块，大量腹水 | — | 入院 |
| 腹部盆腔 CT | 双附件占位、腹膜广泛种植、大网膜饼、腹水 | — | 入院 |
| 腹水细胞学 | 见腺癌细胞 | 阴性 | 入院 |
| 血常规/生化 | 白蛋白低、轻度贫血 | — | 入院 |

### 入院诊断
卵巢上皮性癌（高级别浆液性，Ⅲ C 期，伴腹膜广泛种植）；恶性腹水。

### 诊断依据与鉴别诊断
- 诊断依据（证据链）：绝经后女性腹胀、消瘦、腹水 → CA125 显著升高 → 影像见双附件占位、腹膜种植、网膜饼 → 腹水细胞学见腺癌 → 卵巢癌 Ⅲ C 期。
- 鉴别诊断：

| 疾病 | 鉴别要点 |
| --- | --- |
| 结核性腹膜炎 | 低热盗汗、腹水 ADA 高、细胞学无肿瘤细胞 |
| 肝硬化腹水 | 肝病史、门脉高压表现、SAAG 高 |
| 腹膜癌/消化道肿瘤转移 | 需病理与免疫组化定位来源 |
| 卵巢良性肿瘤/囊肿 | CA125 多不高，影像无种植 |

## 二、首次病程记录

- 病例特点：绝经后女性，腹胀腹水消瘦，CA125 极高，影像示卵巢占位伴腹膜广泛种植，腹水细胞学阳性，属晚期。
- 诊断依据：见上。
- 鉴别诊断：见上表（与结核性腹膜炎、肝硬化腹水鉴别）。
- 诊疗计划：**肿瘤细胞减灭术 + 铂类/紫杉醇化疗**（据评估可先行新辅助化疗再手术）；胸腔/腹腔症状管理；营养支持；评估 BRCA 基因；多学科协作。

---

## 三、日常病程记录

- **入院第 1 天**：完善评估，腹腔穿刺放液缓解腹胀，送腹水细胞学（腺癌）。
- **入院第 3 天**：与患者及家属沟通分期与治疗方案，先行新辅助化疗（紫杉醇 + 卡铂）。
- **入院第 6 天**：腹胀减轻，气促缓解，食欲改善，耐受化疗。
- **入院第 10 天**：一般情况改善，制定后续化疗 + 减灭手术计划，达出院标准（继续治疗）。

---

## 四、出院小结

- 入院情况：腹胀腹水 2 个月，诊断卵巢癌 Ⅲ C 期。
- 诊疗经过：腹水细胞学确诊，行新辅助化疗 + 症状管理，症状改善。
- 出院诊断：卵巢上皮性癌（高级别浆液性，Ⅲ C 期）。
- 出院情况：腹胀减轻，腹水减少，可进食。
- 出院医嘱：按周期行化疗，评估肿瘤细胞减灭术时机；营养支持；建议 BRCA/HRD 检测指导维持治疗；妇科肿瘤随访 CA125 与影像。

---

## 五、教学点 / 临床思维

- **诊断思维（难点）**：绝经后女性"腹胀、腹水、消瘦"易被当消化病，**卵巢癌是"沉默的肿瘤"**，需想到妇科来源（CA125 + 超声）。
- 治疗关键：肿瘤细胞减灭术 + 铂类/紫杉醇化疗；维持治疗（PARP 抑制剂）据基因状态。
- 易漏诊/误诊点：把卵巢癌腹水当"消化不良/结核/肝硬化"而延误。
- 全科思考：绝经后女性新发腹胀腹水需警惕卵巢癌；高危家族史者遗传咨询。
