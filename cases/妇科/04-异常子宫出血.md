# 异常子宫出血 · 妇科

## 元信息

- ID：GYN-AUB-04
- 科室：妇科
- 病种：异常子宫出血（排卵障碍性，AUB-O）
- 类型：常见
- 人群：女，34 岁
- 关键教学点：PALM-COEIN 分类；先排除妊娠与器质病变；止血 + 调整周期 + 防内膜癌
- 适用：出科汇报 / 教学查房

---

## 一、入院记录

### 主诉
月经紊乱、经期延长伴经间期出血 8 个月。

### 现病史
8 个月来月经周期 20–40 天不规律，经期 10–14 天，经间期点滴出血，无痛经、无发热。近 3 个月体重增加 5 kg、压力大。既往多囊卵巢综合征（PCOS）史。

### 既往史 / 个人史 / 婚育史 / 家族史 / 过敏史
PCOS 史；超重；G0P0；无药物过敏史。

### 体格检查
- 生命体征：T 36.6℃，P 82 次/分，R 18 次/分，BP 124/78 mmHg，BMI 27.8。
- 系统查体：体毛略多、无痤疮；妇科检查子宫附件未见异常；无异常阴道排液。

### 入院诊断
异常子宫出血（排卵障碍性 AUB-O）；子宫内膜增生（无 atypia）；PCOS；轻度贫血。

### 诊断依据与鉴别诊断
- 诊断依据（证据链）：月经紊乱、经期长伴经间期出血 → 排除妊娠（HCG 阴性）→ 超声见内膜增厚、卵巢多囊；诊断性刮宫示增生期 → 结合 PCOS 排卵障碍 → AUB-O。
- 鉴别诊断：

| 疾病 | 鉴别要点 |
| --- | --- |
| 妊娠相关出血 | HCG 阳性（异位/流产/滋养细胞病） |
| 子宫肌瘤/息肉/腺肌病 | 超声/宫腔镜见结构性病变 |
| 子宫内膜癌/不典型增生 | 病理见恶性/不典型，需警惕 |
| 凝血/甲状腺/肝病 | 相应化验异常 |

## 二、首次病程记录

- 病例特点：青年女性，PCOS 背景，排卵障碍性 AUB，内膜增厚经刮宫为增生（无 atypia），伴贫血。
- 诊断依据：见上。
- 鉴别诊断：见上表（重点排除妊娠与器质性/恶性病变）。
- 诊疗计划：**止血**（激素/刮宫已行）+ **调整周期**（孕激素后半周期或短效避孕药）；纠正贫血、减重；**长期无排卵者保护子宫内膜（周期性孕激素）防内膜癌**；随访。

## 三、日常病程记录

- **入院第 1 天**：完成诊断性刮宫止血，病理为增生（无 atypia）；予补铁纠正贫血。
- **入院第 3 天**：出血明显减少，与患者沟通周期调整方案（短效口服避孕药/孕激素）。
- **入院第 5 天**：出血停止，宣教减重、规律作息与周期管理。
- **入院第 7 天**：症状缓解，制定长期随访，达出院标准。

---

## 四、出院小结

- 入院情况：月经紊乱经期延长 8 个月，AUB-O 伴内膜增生。
- 诊疗经过：诊断性刮宫止血 + 激素周期调整 + 纠正贫血，出血控制。
- 出院诊断：异常子宫出血（AUB-O）；子宫内膜增生（无 atypia）；PCOS；轻度贫血。
- 出院情况：无异常出血，贫血改善。
- 出院医嘱：按方案周期用药（勿漏服）；减重、规律生活；**长期无排卵者需周期性孕激素保护内膜**；每 3–6 个月复查超声与内膜（必要时再次活检）；如出血量多、经期过长及时就诊。

---

## 五、教学点 / 临床思维

- 诊断关键：AUB 先按 **PALM-COEIN** 分类，**首先排除妊娠**，再查结构与凝血/内分泌因素。
- 治疗关键：止血 → 调整周期 → 保护内膜（长期无排卵者防内膜癌）。
- 易漏诊/误诊点：把 AUB 当"月经不调"而漏诊内膜病变/妊娠；忽视长期无排卵的内膜癌风险。
- 全科思考：青春期/育龄期/绝经后 AUB 处理原则不同，需个体化管理。
