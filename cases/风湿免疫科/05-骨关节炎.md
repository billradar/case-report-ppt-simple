# 骨关节炎 · 风湿免疫科 / 骨科

## 元信息

- ID：RHE-OA-05
- 科室：风湿免疫科 / 骨科
- 病种：膝关节骨关节炎（中重度）
- 类型：常见
- 人群：女，64 岁
- 关键教学点：负重关节慢性痛 + 短晨僵；影像见骨赘/间隙变窄；综合阶梯治疗
- 适用：出科汇报 / 教学查房

---

## 一、入院记录

### 主诉
双膝疼痛、活动受限 3 年，加重 2 个月。

### 现病史
3 年来双膝上下楼及久走后疼痛，休息缓解，晨僵 <15 分钟，逐渐出现关节麻木、摩擦感。2 个月来疼痛加重、行走距离缩短。既往体健、绝经 15 年、体型偏胖。

### 既往史 / 个人史 / 婚育史 / 家族史 / 过敏史
绝经后；超重；无外伤史；无药物过敏史。

### 体格检查
- 生命体征：T 36.4℃，P 76 次/分，R 18 次/分，BP 134/82 mmHg，BMI 29.1。
- 系统查体：双膝关节肿大、内侧压痛、骨摩擦音，活动受限；双膝无红肿热；浮髌试验（−）。

### 辅助检查
| 项目 | 结果 | 参考区间 | 时点 |
| --- | --- | --- | --- |
| 双膝 X 线 | 内侧间隙变窄、骨赘、软骨下骨硬化 | — | 入院 |
| ESR / CRP | 正常 | — | 入院 |
| 抗 CCP / 类风湿因子 | 阴性 | 阴性 | 入院 |

| 关节超声 | 软骨变薄、少量积液 | — | 入院 |

### 入院诊断
双膝关节骨关节炎（中重度）；超重。

### 诊断依据与鉴别诊断
- 诊断依据（证据链）：中老年女性、负重关节慢性痛 + 短晨僵（<30 min）→ 骨摩擦音、活动受限 → X 线见间隙变窄、骨赘、硬化 → 炎症指标与自身抗体阴性 → 骨关节炎。
- 鉴别诊断：

| 疾病 | 鉴别要点 |
| --- | --- |
| 类风湿关节炎 | 小关节对称受累、晨僵长、抗 CCP 阳性 |
| 痛风 | 急性单关节炎、高尿酸、痛风石 |
| 假痛风 | 影像见软骨钙化，关节液见焦磷酸钙结晶 |
| 感染性关节炎 | 红肿热痛、发热，关节液脓性 |

## 二、首次病程记录

- 病例特点：老年超重女性，双膝负重关节退变性疼痛，晨僵短，影像典型，炎症指标正常。
- 诊断依据：见上。
- 鉴别诊断：见上表。
- 诊疗计划：阶梯治疗——生活方式（减重、股四头肌锻炼、避免负重）→ 对乙酰氨基酚/NSAIDs → 关节腔注射 → 必要时关节置换评估；宣教与康复。

---

## 三、日常病程记录

- **入院第 1 天**：予塞来昔布 + 氨基葡萄糖，指导股四头肌等长收缩训练与减重。
- **入院第 3 天**：疼痛减轻，行走改善，宣教避免爬楼、久站。
- **入院第 5 天**：膝关节腔注射玻璃酸钠，配合康复训练。
- **入院第 7 天**：疼痛明显缓解，制定长期康复与随访。
- **入院第 8 天**：达出院标准。

## 四、出院小结

- 入院情况：双膝疼痛 3 年加重 2 个月，诊断膝关节骨关节炎。
- 诊疗经过：药物 + 关节腔注射 + 康复训练，症状改善。
- 出院诊断：双膝关节骨关节炎（中重度）；超重。
- 出院情况：疼痛缓解，可短距离行走。
- 出院医嘱：减重、股四头肌锻炼、避免爬楼久站；必要时止痛药；定期复诊；如关节肿痛加重、活动明显受限评估关节置换。

---

## 五、教学点 / 临床思维

- 诊断关键：负重关节 + 短晨僵 + 典型影像；与炎性关节病鉴别。
- 治疗关键：阶梯治疗，生活方式与康复是基础；避免过度用药。
- 易漏诊/误诊点：把骨关节炎当"风湿"滥用激素；忽视继发因素（如痛风、感染）。
- 全科思考：骨关节炎是慢病，减重与运动是最有效干预。
