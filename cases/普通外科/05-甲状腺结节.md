# 甲状腺结节 · 普通外科

## 元信息

- ID：SUR-THY-05
- 科室：普通外科 / 甲状腺外科
- 病种：甲状腺结节（结节性甲状腺肿，TI-RADS 3 级）
- 类型：常见
- 关键教学点：超声分级（TI-RADS）；良恶性评估与 FNA；随访或手术指征
- 适用：出科汇报 / 教学查房

---

## 一、入院记录

### 主诉
发现颈前肿物 2 个月。

### 现病史
2 个月前无意发现颈前偏左肿物，无痛、无吞咽困难、无声音嘶哑、无呼吸困难，无发热、心悸、多汗。肿物无明显增大。既往体健。

### 既往史 / 个人史 / 婚育史 / 家族史 / 过敏史
既往体健；无颈部放射接触史；无甲状腺疾病家族史；无药物过敏史。

### 体格检查
- 生命体征：T 36.5℃，P 78 次/分，R 18 次/分，BP 124/78 mmHg。
- 系统查体：颈前左侧可及约 2 cm 结节，质中、边界清、随吞咽上下移动、无压痛；颈部无肿大淋巴结；无突眼。

### 入院诊断
甲状腺结节（结节性甲状腺肿，TI-RADS 3 级，FNA 良性）。

### 诊断依据与鉴别诊断
- 诊断依据（证据链）：颈前无痛性结节随吞咽活动 → 超声 TI-RADS 3 级、边界清 → 甲功正常 → FNA 良性 → 良性甲状腺结节。
- 鉴别诊断：

| 疾病 | 鉴别要点 |
| --- | --- |
| 甲状腺癌 | 超声见微钙化、边界不清、垂直生长，FNA 恶性 |
| 甲状腺腺瘤 | 单发、包膜完整，需病理区分 |
| 桥本甲状腺炎 | 弥漫肿大、抗体阳性、质地韧 |
| 甲亢/毒性结节 | 甲功异常、可伴高代谢症状 |

## 二、首次病程记录

- 病例特点：中年，单发甲状腺结节，超声 TI-RADS 3 级、FNA 良性，甲功正常。
- 诊断依据：见上。
- 鉴别诊断：见上表。
- 诊疗计划：良性结节以**随访**为主（每 6–12 个月超声）；如结节增大明显或出现压迫/可疑征象行 FNA 或手术；宣教定期复查。

- **入院第 1 天**：完善超声、甲功与 FNA，结果良性；宣教随访与复查时间。
- **入院第 2 天**：无不适，无压迫症状，制定随访计划。
- **入院第 3 天**：达出院标准。

## 四、出院小结

- 入院情况：发现颈前肿物 2 个月，甲状腺结节（良性）。
- 诊疗经过：完成超声 TI-RADS 分级与 FNA，确认为良性结节，予随访方案。
- 出院诊断：甲状腺结节（结节性甲状腺肿，TI-RADS 3 级，FNA 良性）。
- 出院情况：无不适，颈部无压迫症状。
- 出院医嘱：每 6–12 个月复查甲状腺超声与甲功；如结节迅速增大、出现声音嘶哑/吞咽困难/颈部淋巴结肿大及时就诊。

---

## 五、教学点 / 临床思维

- 诊断关键：超声（TI-RADS）+ 甲功 + FNA 是核心；大多数结节为良性。
- 治疗关键：良性结节随访为主，避免过度手术；可疑者 FNA/手术。
- 易漏诊/误诊点：忽视超声恶性征象（微钙化、边界不清、垂直生长）；漏查颈部淋巴结。
- 全科思考：甲状腺结节高发，规范评估与随访、避免过度治疗。
