# 病例库（case-library）

面向病例汇报 / 出科汇报 / 教学查房的**去标识化教学病例库**。每个科室 **5 个常见病种 + 1 个疑难杂症**；每个病例含**入院记录 + 首次病程 + 每日病程 + 出院小结**。

> 规模：**20 个科室 · 120 个病例 + 8 例死亡病例讨论**（共 129 个文件，含模板）。

## 选用规则

1. **先匹配**：按用户给出的科室 / 病种 / 人群匹配病例。
2. **匹配到直接用**：数值可微调，但同一份汇报内必须自洽。
3. **未匹配到**：取同科室、同系统病例改造，或据 [cases/_TEMPLATE.md](../cases/_TEMPLATE.md) 生成。
4. **一致性核对**：数值、单位、参考区间、日期、诊断名称全篇一致。
5. **尊重项目边界**：`case-ppt-simple` 只填充既有版式；`case-report-ppt` 可重排但保留视觉语言。
6. **脱敏**：库内已去标识；混入真实资料前先删除标识信息。
7. **危急重症可设死亡病例**：对危重、进展凶险或易延误的病种，可**随机**设计为死亡病例——把"出院小结"替换为**死亡讨论**（死亡经过、抢救记录、死亡诊断、死亡原因、经验教训与改进），并归入 `cases/死亡病例讨论/`。

## 扩展病例库

1. 复制 `cases/_TEMPLATE.md` 为 `cases/<科室>/<序号>-<病种>.md`，按模板填写。
2. 在本文件对应科室下补一行病种（保持"常见 5 + 疑难 1"结构）。
3. 证据链完整：病史 → 体征 → 关键检查 → 排除 → 结论；关键检查必须有单位与参考区间；病程记录体现"病情变化 → 处理 → 效应"。
4. 死亡病例：把"出院小结"替换为"死亡讨论"，归入 `cases/死亡病例讨论/`，并对危急重症随机分配。
