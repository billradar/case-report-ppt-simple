# 演示文稿工具发现与选择

1. 列出当前会话**已经连接**的 MCP 工具及其他可用桌面自动化能力。不要按系统预设某个项目，也不要假设工具名称或功能；检查实际工具说明并做只读探测。不要为完成这一步自动安装软件、克隆项目、修改 MCP 配置或要求重启会话。
2. 先验证能否定位用户指定的文件、复制工作副本、读取页面和形状。再以工作副本的一页测试文本局部替换、仅对指定字符范围标 `#EE0000`、复制同类页、保存与重新打开；核验布局、字体、页码和动画。按单项能力选择工具，必要时组合不同已可用工具。
3. 用户要求看到过程时，确认工具控制的是其可见桌面会话中的演示文稿窗口，并在编辑时显示目标页。文件级 `.pptx` 写入不能被描述为窗口可见编辑；单纯存在 MCP 也不代表已具备字符级格式控制。
4. 如果工具只支持整框替换或着色，可能重置富文本；如果只支持新建幻灯片，不可假定能复制原模板页面。功能不足时不要勉强调用，说明具体缺口和可完成部分，再让用户选择是否接受非可视或低保真的替代流程。

本技能不绑定 WPS、PowerPoint、LibreOffice 或某个 MCP 仓库。选用依据是**当前已连接工具的实际能力**以及用户对可见操作、版式和字体的要求。
