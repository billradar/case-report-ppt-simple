# 病例内容与医学一致性

## 统一病例数据源

先建立下表（可在备注、受控草稿或结构化数据中维护），再从中填充所有幻灯片。若操作者自行提供了详细病例资料（病史、查体、检验、影像、诊断、治疗等），以提供资料为唯一事实来源，逐项填入下表；仅补全格式与表述，不补造未提供的内容。

| 模块 | 最低字段 | 核验 |
| --- | --- | --- |
| 基本资料 | 去标识化年龄段、性别、入院/就诊时间线 | 不出现姓名、证件、电话、住址、病案号等标识符 |
| 主诉与现病史 | 症状、起病、病程、关键阴阳性、时间点 | 与后续诊断和处置时间线一致 |
| 既往史/用药/过敏史 | 相关风险因素和否认项 | 不把未提供内容写成“无” |
| 查体 | 阳性体征、关键阴性体征、检查时间 | 不混淆入院、复查和出院时状态 |
| 辅助检查 | 名称、值、单位、参考范围、时间、来源 | 数字、单位、上下箭头和引用一致 |
| 诊断 | 初步/最终诊断、鉴别诊断及证据 | 明确诊断阶段；不把鉴别写成确诊 |
| 治疗与转归 | 措施、剂量/频率（如已提供）、观察结果、时间 | 因果表述有证据；不夸大疗效 |
| 反思 | 问题、原因、改进 | 区分病例事实和教学观点 |

## 诊断证据链

诊断页应让听众能顺着证据得到结论：

```text
病史关键点 → 阳性体征 → 异常检查/特异性证据 → 排除或鉴别要点 → 诊断结论
```

- 每一环只保留改变诊断概率或处置的要点；不要堆叠无关正常值。
- 将关键阳性事实、异常数值和最终诊断的关键短语标为 `#EE0000`；同一页的红色只承担“诊断证据”这一语义。
- 红色不是替代解释：数值旁保留单位、参考范围、检查日期/时点；影像/病理须说明检查类型与日期。
- 用“支持”“提示”“与……一致”“待结合……”表达证据强度；没有充分依据时不写“证实”。

## 一致性检查

逐项比对：

1. 年龄、性别、生理状态与疾病/治疗是否相容；
2. 所有日期是否按病程先后排列，且“入院、检查、干预、复查、出院”互不矛盾；
3. 检查值、单位、参考范围和异常方向是否在各页一致；
4. 初步诊断、鉴别诊断、最终诊断之间是否清楚区分；
5. 治疗的适应证、时序、剂量和疗效陈述是否能回链到已提供资料；
6. “无/否认/正常/改善/治愈”等绝对措辞是否有来源；否则改为“未提供”“未见记录”或“待核实”。

发现矛盾时，优先保留原始资料与时间戳，在页面/交付说明中列为待核实项；不得自行选择看似更合理的一种。

## 去标识化

移除或泛化直接标识符与可组合识别线索：姓名、照片、证件号、联系方式、住址、精确生日、病案号、条码、完整住院号、机构内可回溯链接及截图中的同类信息。影像截图、检验单和页眉页脚都需单独检查。

保留教学必要性与最小化原则：年龄用区间或“××岁”按授权展示；时间可相对化为“入院第 N 天”。如机构有自己的脱敏标准，以机构要求为准。

幻灯片正文、页脚、备注和图片替代文本不得出现“教学病例模拟数据”“模拟数据”“仅用于演示/病例汇报演示”等模拟或演示字样；确需说明数据为教学模拟或脱敏时，只写在交付说明或受控草稿中，不写入幻灯片。

## 临床边界

本技能用于呈现和一致性审查，不提供患者个体化诊疗决策。最终诊断、治疗方案、药物剂量和对外病例材料应由具备资质的临床人员审核确认。
